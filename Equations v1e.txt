"incidence_rate_robust_to_pre-frail"[gender, age] = "raw_incidence_rate_robust_to_pre-frail"*vector_for_age_greater_than_frailty_start_age[age]
    UNITS: Dimensionless/Year
    DOCUMENT: Data sources
    =============
    
    Wei, Kai, et al. "Nutritional and frailty state transitions in the Singapore Longitudinal Aging Study." The Journal of nutrition, health and aging 22.10 (2018): 1221-1227.
    
    Cheong, C. Y., et al. "Risk factors of progression to frailty: findings from the Singapore longitudinal ageing study." The Journal of nutrition, health and aging 24.1 (2020): 98-106.
    
    
    
    Base transition rates:
      Robust → Prefrail : 43.4% over 5 years  (Wei et al. 2018, Table 3, SLAS-2)
      Prefrail → Frail  : 22.28% over 4.5 years (Cheong et al., Results, SLAS-2)
    
    Age and gender log-odds coefficients (borrowed from Cheong et al., same SLAS-2 cohort):
      β_age    = ln(1.07) = 0.06766 per year of age
      β_female = ln(0.91) = −0.09431 (female indicator)
    
    LOGISTIC FRAMEWORK
    -------------------------
    For each transition, the cumulative probability P over the follow-up horizon T is:
    
      logit(P) = ln[P/(1−P)] = α + 0.06766 × age − 0.09431 × female
    
    where female = 1 for women, 0 for men, and α is a transition-specific intercept.
    
    INTERCEPT DERIVATION — Robust → Prefrail
    --------------------------------------------------
    Anchored at Wei Table 1 Robust subgroup means:
      Mean age     = 64.8 years
      Prop. female = 355/570 = 62.3%
      Base rate    = 43.4% over 5 years
    
      logit(0.434) = ln(0.434/0.566) = −0.266
    
      Covariate contribution C = 0.06766 × 64.8 − 0.09431 × 0.623
                               = 4.384 − 0.059 = 4.325
    
      α = −0.266 − 4.325 = −4.591
    
    Gender-specific intercepts (absorbing β_female × female):
      Male   (female=0): α_male   = −4.591
      Female (female=1): α_female = −4.591 − 0.09431 = −4.685
    
    Verification: at age 64.8, 62.3% female →
      logit(P) = −4.591 + 4.384 − 0.059 = −0.266 → P = 43.4% ✓
    
    INTERCEPT DERIVATION — Prefrail → Frail
    ---------------------------------------------
    Anchored at Cheong et al. sample means:
      Mean age     = 65.62 years
      Prop. female = 63.9%
      Base rate    = 22.28% over 4.5 years
    
      logit(0.2228) = ln(0.2228/0.7772) = −1.249
    
      Covariate contribution C = 0.06766 × 65.62 − 0.09431 × 0.639
                               = 4.439 − 0.060 = 4.379
    
      α = −1.249 − 4.379 = −5.628
    
    Gender-specific intercepts:
      Male   (female=0): α_male   = −5.628
      Female (female=1): α_female = −5.628 − 0.09431 = −5.722
    
    Verification: at age 65.62, 63.9% female →
      logit(P) = −5.628 + 4.439 − 0.060 = −1.249 → P = 22.28% ✓
    
    ANNUAL TRANSITION RATE FORMULA
    -------------------------------
    The logit equation gives cumulative probability P over horizon T (5 or 4.5 years).
    Assuming constant hazard, the annual rate r is:
    
      r(age, gender) = 1 − (1 − P(age, gender))^(1/T)
    
    FINAL PARAMETER VALUES ENTERED IN MODEL
    ----------------------------------------
    OR_robust_to_prefrail_Alpha[male]   =  4.591
    OR_robust_to_prefrail_Alpha[female] =  4.685
    OR_prefrail_to_frail_Alpha[male]    =  5.628
    OR_prefrail_to_frail_Alpha[female]  =  5.722
    OR_robust_to_prefrail_Beta[male]    =  0.0677
    OR_robust_to_prefrail_Beta[female]  =  0.0677
    OR_prefrail_to_frail_Beta[male]     =  0.0677
    OR_prefrail_to_frail_Beta[female]   =  0.0677
    
    Note: Alpha values are stored as positive numbers in the model.
    The Stella formula uses them as (Alpha − Beta × age), matching
    the sign convention logit(P) = α − β × age, where the negative
    sign on Beta reflects increasing transition probability with age.
    
    IMPORTANT: the model uses these estimates above age 50, and this age threshold is hard-coded!

    EXTENSION TO MODEL AGE BANDS
    -----------------------------
    The model covers single-year age cohorts from NewBorn to Age100andOver,
    with frailty stocks active from age 55 onwards (Age_55_plus_vector = 1
    for ages 55-100+, 0 otherwise).
    
    Age 0-54  : initial_frailty_prevalence = 0
                Initial_prefrailty_prevalence = 0
    
    Age 55-59 : No Vaingankar data available (survey started at age 60).
                Assumption: prevalence equals the 60-74 band values,
                i.e., frailty = 3.5%, pre-frailty = 37.9%.
                Rationale: frailty is rare below 60 and the 60-74 band
                is already dominated by the 60-64 sub-group, making it
                a conservative upper bound for ages 55-59.
    
    Age 60-74 : initial_frailty_prevalence      = 0.035
                Initial_prefrailty_prevalence   = 0.379
    
    Age 75-84 : initial_frailty_prevalence      = 0.123
                Initial_prefrailty_prevalence   = 0.475
    
    Age 85+   : initial_frailty_prevalence      = 0.246
                Initial_prefrailty_prevalence   = 0.534
    
    NORMALISATION
    -------------
    The three prevalence values (robust + pre-frail + frail) must sum
    exactly to 1.0 for each cell. Checking against Vaingankar:
    
      60-74 :  0.586 + 0.379 + 0.035 = 1.000 ✓
      75-84 :  0.402 + 0.475 + 0.123 = 1.000 ✓
      85+   :  0.220 + 0.534 + 0.246 = 1.000 ✓
    
    No normalisation adjustment required.
    
    APPLICATION IN STELLA
    ----------------------
    These prevalence values are applied uniformly across all race and
    gender dimensions within each age band, as Vaingankar reports no
    statistically significant race differences in frailty prevalence
    (p = 0.022 at bivariate level but not retained in the adjusted
    regression), and no significant sex difference in frailty
    (p = 0.082, Table 1).
    
      INIT frail_undiagnosed    = resident_population * initial_frailty_prevalence
      INIT pre-frail_undiagnosed = resident_population * Initial_prefrailty_prevalence
      INIT robust_people        = resident_population * (1 - initial_frailty_prevalence
                                                           - Initial_prefrailty_prevalence)
    
    The diagnosed stocks (frail_diagnosed, pre-frail_diagnosed) are
    initialised at zero, consistent with the assumption that no
    screening programme existed at the 2010 simulation start date.

      Frail     vs robust:  HR = 2.18
      Severity multiplier   g = HR_frail / HR_prefrail = 2.18 / 1.51 = 1.44
    
    Source
    ------
    Li 2026, meta-analysis, subgroup by frailty severity (both vs robust):
      Pre-frail: HR = 1.51  95% CI 1.37-1.67   PI 1.00-2.29
      Frail:     HR = 2.18  95% CI 1.72-2.75   PI 0.67-7.08
    Severity gradient (pre-frail vs frail) significant: Q = 7.88, p < .01.
    
    WHY REPARAMETERISE
    ------------------
    Frail and pre-frail RR come from the same studies, share the robust
    reference group, and are constrained by biology: RR_frail >= RR_prefrail
    (the gradient cannot run backwards). Swept as two independent factors over
    overlapping ranges, a full-factorial design produces incoherent cells where
    pre-frail RR exceeds frail RR.
    
    Fix: do not sweep frail RR directly. Sweep pre-frail RR and a severity
    multiplier g, and DERIVE frail RR = pre-frail RR x g, with g >= 1. This
    keeps frail RR >= pre-frail RR in every cell automatically, keeps the design
    full / balanced / orthogonal (no post-hoc filtering), and makes the gradient
    STEEPNESS its own testable factor -- which is the effect Li shows is
    significant.
    
    FACTOR A -- PRE-FRAIL RR  (basis: prediction interval)
    ------------------------------------------------------
    PI used (not CI): Singapore is effectively "a new study", so spread should
    include between-study heterogeneity. (CI basis is too tight -> factor inert.)
      ln(1.51) = 0.412
      SE_PI = (ln 2.29 - ln 1.00) / 3.92 = 0.211
      Interquartile (z = +/-0.674):
         Q1 = 1.51 x exp(-0.674 x 0.211) = 1.31
         Q3 = 1.51 x exp(+0.674 x 0.211) = 1.74
      Range: 1.31 - 1.74,  base 1.51.
    
    FACTOR B -- SEVERITY MULTIPLIER g  (basis: gradient precision, Q-statistic)
    --------------------------------------------------------------------------
    g is estimated from the difference of the two log-HRs.
      ln(g) = ln(2.18) - ln(1.51) = 0.779 - 0.412 = 0.367
      From the subgroup test:  SE(ln g) = sqrt( ln(g)^2 / Q )
                                         = sqrt( 0.367^2 / 7.88 ) = 0.131
      Consistency check (treating subgroups as independent at CI level):
         sqrt(SE_frail_CI^2 + SE_prefrail_CI^2) = sqrt(0.120^2 + 0.050^2) = 0.130  ok
      Interquartile (z = +/-0.674):
         g_Q1 = exp(0.367 - 0.674 x 0.131) = 1.32
         g_Q3 = exp(0.367 + 0.674 x 0.131) = 1.58
      Range: 1.32 - 1.58,  base 1.44.
    
      Note: g = 1 (no gradient) sits ~2.8 SE below the mean (~0.3rd percentile),
      i.e. the gradient is robustly > 1. g >= 1 is therefore essentially always
      satisfied; if a "weak gradient" stress scenario is wanted, set g = 1.0
      explicitly as a deliberate floor (frail RR = pre-frail RR at that point).
    
    DERIVED -- FRAIL RR
    -------------------
      frail_RR = prefrail_RR x g          (computed, not a free factor)
      Base:          1.51 x 1.44 = 2.18
      Implied range across the design: 1.31x1.32 = 1.73  to  1.74x1.58 = 2.75
      (Narrower than frail's standalone PI IQR of 1.45-3.27 by design: frail
       uncertainty is now decomposed into "where pre-frail sits" x "how steep
       the gradient is", rather than treated as free.)
    
    DOE FACTOR SETTINGS  (two factors, swept independently, coherent by construction)
    --------------------------------------------------------------------------------
      Pre-frail RR:          1.31  /  1.51  /  1.74
      Severity multiplier g: 1.32  /  1.44  /  1.58
      Frail RR (output):     derived per cell as prefrail_RR x g
    
      Diagonal scenarios, for reference:
         Optimistic:    prefrail 1.31, g 1.32  -> frail 1.73
         Base:          prefrail 1.51, g 1.44  -> frail 2.18
         Conservative:  prefrail 1.74, g 1.58  -> frail 2.75
    
    CAVEAT -- DEATH-BALANCE INTERACTION
    -----------------------------------
    These RRs are weights in weighted_frailty_stock; relative_risk_mortality_robust
    is back-solved from them so total frailty deaths = resident deaths. Raising
    them shifts the death burden onto frail/pre-frail and LOWERS the implied
    robust RR; pushed too high, relative_risk_mortality_robust is forced to 0 and
    the balance breaks. At the conservative corner (frail RR ~ 2.75) confirm the
    implied robust RR is still positive.

      ln(g)           ~ Normal(0.367, 0.131^2)
      frail_RR = prefrail_RR x g
      Sampled independently; P(g < 1) ~ 0.3%, so coherence holds in essentially
      all draws.

    DERIVING A SCENARIO RANGE
    -------------------------
    An RR is treated as log-normal: ln(RR) is approximately normal, and the
    published 95% CI is symmetric on the log scale. This is the standard
    sampling model for a relative risk, so any quantile can be recovered
    from the reported CI.
    
    Standard error on the log scale:
      ln(0.46) = -0.777
      ln(0.20) = -1.609   ln(1.04) = +0.039
      SE = (ln(upper) - ln(lower)) / (2 x 1.96)
         = (0.039 - (-1.609)) / 3.92
         = 0.420
    
    Consistency check (confirms log-normal is appropriate):
      geometric mean of CI bounds = sqrt(0.20 x 1.04) = 0.456 ~ 0.46
      i.e. the CI is symmetric about the point estimate on the log scale.
    
    QUANTILES
    ---------
    General form:   RR(p) = 0.46 x exp(z_p x 0.420)
    where z_p is the standard-normal quantile.
    
      Interquartile (Q1, Q3), z = +/-0.674:
         Q1 = 0.46 x exp(-0.674 x 0.420) = 0.35
         Q3 = 0.46 x exp(+0.674 x 0.420) = 0.61
    
      80% interval, z = +/-1.28:    0.27 - 0.79
      90% interval, z = +/-1.645:   0.23 - 0.92
      95% interval, z = +/-1.96:    0.20 - 1.04  (as published)

    CAVEAT
    ------
    The IQR is the central 50% of the distribution (the 50% CI). It is used
    as the routine sensitivity band, but it deliberately discards both tails.
    The 95% CI crosses 1.0 (upper bound 1.04), so this single small RCT does

    as the full uncertainty.

    run RR ~ 1.0 as a separate, explicitly labelled "intervention ineffective"
    stress scenario, rather than letting the IQR average that possibility away.
